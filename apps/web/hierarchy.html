Hierarchical facets · Joint uncertainty

Missing labels can create impossible doubts.

We derived a way to compute ranking uncertainty while respecting a tag hierarchy. It also exposes what happens when a hierarchy relation is wrong.

This page demonstrates a conditional mathematical model. The dataset experiment uses scripted requests and artificially masked public film/book tags. It does not measure personal enjoyment.

The result we can check

Our formulation computes an exact pairwise gap with one minimum cut on a graph of 3m + 2 nodes, where m is the number of facets. It keeps one shared preference vector and returns an attaining label/weight witness.

Assumptions and what the guarantee means

Binary labels; additive signed matching weights in independent intervals; valid child→parent implications; correct observed facts; independent item completions. No guarantee of enjoyment, calibrated semantics, arbitrary weight constraints or unrestricted label incompatibilities. A structural fault budget gives a conservative upper bound and may widen it.

Graph cuts, minimax regret and Lagrangian bounds are established. This specific formulation and experiment are a candidate project contribution; worldwide novelty has not been established.
